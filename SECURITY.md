# Security

The HumanEval portion executes Python generated by a language model. Treat it
as untrusted code.

Use the supplied evaluator container. It runs with:

- no network;
- a read-only root filesystem;
- no inherited API keys or other environment variables;
- bounded memory, process count, and execution time;
- a disposable temporary filesystem.

Do not run `score_results.py --execute-code` directly on a workstation that
has credentials, personal files, network access, or privileged services.

The RunPod API key is a secret. Do not commit it, paste it into issue reports,
or place it in a `.env` file inside this repository. Set it in the calling
shell only and revoke it when the evaluation period ends.
